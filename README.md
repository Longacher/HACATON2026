# Отклик — платформа доверительных обращений

«Отклик» — веб-платформа для безопасной и конфиденциальной подачи обращений. Пользователь может рассказать о ситуации без регистрации, получить трек-номер и продолжить диалог со специалистом. Операторская часть помогает команде распределять обращения, отслеживать статусы и отвечать заявителям

Проект построен на Next.js, React и TypeScript. Интерфейс выполнен в фиолетово-синей гамме, ориентирован на мобильные устройства и включает плавные переходы, адаптивные карточки и единый визуальный стиль пользовательской и административной частей.

## Возможности

### Пользовательская часть

* Анонимная подача обращения без регистрации.
* Пошаговая форма: кто обращается, что произошло, результат.
* Выбор категории или свободное описание ситуации.
* Добавление вложений и предупреждение о кризисных ситуациях.
* Проверка обращения по трек-номеру.
* Безопасный диалог со специалистом и возможность дополнить обращение.

### Административная часть

* Рабочий стол оператора с приоритетами, KPI и очередью обращений.
* Фильтрация по статусу, приоритету и назначенному специалисту.
* Карточка обращения с историей событий, чатом и внутренними заметками.
* Рабочее место эксперта для подготовки ответа заявителю.
* Календарь команды с недельной лентой, agenda и доступностью специалистов.
* Справочники категорий, правила маршрутизации и управление командой.
* Обезличенная аналитика и экспорт агрегированных показателей.

* Next.js 16 (App Router)

## Маршруты

* `/` — главная страница платформы.
* `/submit` — создание обращения.
* `/status` — проверка статуса по трек-номеру.
* `/queue` — очередь обращений оператора.
* `/expert` — рабочее место эксперта.
* `/calendar` — календарь команды.
* `/analytics` — аналитика.
* `/admin` — рабочий стол админки.
* `/admin/categories` — категории и маршрутизация.
* `/admin/team` — команда и роли.

## Установка

### Требования

* Node.js 18 или новее (рекомендуется Node.js 20+).
* npm 9 или новее.

### Запуск проекта

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

### Production-сборка

```bash
npm run build
npm run start
```

Проверка качества кода:

```bash
npm run lint
```

## Приватность

Регистрация не требуется. Трек-номер не содержит персональных данных и показывается пользователю один раз. В прототипе не используются IP/User-Agent, сторонние трекеры и контакты заявителя. Аналитика предназначена только для агрегированных показателей и метаданных.

## Ограничения прототипа

Демо-данные и сообщения хранятся в состоянии интерфейса и пока не подключены к серверному API. Для production-версии потребуются авторизация сотрудников, постоянное хранилище обращений, push-уведомления, антивирусная проверка файлов, журналирование действий и интеграция ML-классификации.
