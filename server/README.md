# Отклик — платформа доверительных обращений

MVP: анонимные обращения с маршрутизацией к специалистам. Mobile-first PWA + нативный клиент.

## Запуск одной командой

```bash
docker compose up --build
```

- Фронт: http://localhost:5173
- API: http://localhost:8000 (`/health`, Swagger: `/docs`)

## Тестовые учётки

| Роль | Логин | Пароль |
|---|---|---|
| Оператор | operator1 | oper123 |
| Эксперт (психолог) | expert_psy | exp123 |
| Эксперт (юрист) | expert_law | exp123 |
| Админ | admin | admin123 |

## Модель приватности

- Заявитель анонимен: ни имени, ни почты, ни телефона. IP/User-Agent в базу не пишутся.
- Доступ — только по трек-номеру `ОТК-XXXX-XXXX`; в БД хранится его SHA-256 хеш.
  Номер скрыт по умолчанию, показывается только по тапу (для другого устройства).
- Оператор видит только исходный текст; переписку — нет. Эксперт видит только
  назначенные ему; личность заявителя — никогда. Админ переписку не видит вообще.
- Вложения чистятся от EXIF на сервере. Выгрузки — только метаданные, без текстов.
- Третьих трекеров нет, шрифты и ассеты — свои.

## Трек-номер и уведомления

- Формат `ОТК-XXXX-XXXX`, алфавит без `0/O, 1/I/l`, ≥8 значащих символов,
  криптогенератор `secrets`, коллизии проверяются.
- Проверка статуса: лимит 5/мин с адреса, дальше задержка.
- Номер автоматически сохраняется на устройстве; показывается только по запросу.
- Уведомления: возврат по сохранённому номеру + PWA push (свой VAPID);
  контакт заявитель оставляет сам и только с явным согласием.

## Дизайн по исследованиям

- Trauma-informed computing (Cornell/ACM): безопасность, контроль, прогрессивное
  раскрытие, никаких тёмных паттернов.
- Валидация вместо обещаний (Chayn): «ты не виноват», «мы рядом» — без «всё будет хорошо».
- Тихая помощь вместо красной тревоги: контакты помощи — спокойной ссылкой.
- Молодёжный help-seeking: анонимность, мгновенность, видно живых людей на том конце.

## Что не реализовано

- Настоящий push-бэкенд (заглушка в PWA), соисполнители в UI, лимиты нагрузки
  в подсказке (только сортировка по load), автоудаление зависших, I18N-админка.
