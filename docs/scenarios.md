# Сценарии приёмки (С1–С8) — как они проходят в MVP

## С1 Подача обращения свободным текстом (мобильное)
1. Заявитель открывает приложение, на Home видит объяснение сервиса. ✅
2. Выбирает «Школьник» — интерфейс на «ты» (тон переключается). ✅
3. «Своими словами» → TextInput. ✅
4. Уточняющие вопросы — необязательные. ✅
5. Вложение (опционально) — эндпоинт поддерживает files; в приложении кнопка
   не инициализирована (см. «нереализованное»). ✅/⚠️
6. Отправка → трек-номер, кнопки «Скопировать»/«Проверить статус». ✅

## С2 Подача по категории от взрослого (мобильное)
1. «Родитель»/«Педагог» → интерфейс на «вы». ✅
2. Список категорий из `${api}/categories` (сид из ТЗ). ✅
3. Пункт «Не знаю, как назвать» → ведёт к свободному описанию. ✅
4. Обращение попадает в очередь оператора. ✅

## С3 Работа оператора (веб)
1. `/operator/queue` — очередь новых, срочные/кризисные сверху. ✅
2. Открытие обращения + «Подсказка системы» по категории (`/operator/hint`). ✅
3. Уточнение категории, приоритет. ✅
4. Назначение исполнителя → статус «Распределено». ✅
5. Второе отклоняется как спам с причиной (`action: reject`). ✅

## С4 Работа эксперта (веб)
1. `/expert/appeals` — только назначенные (и соисполнительство). ✅
2. «Взять в работу» → «В работе». ✅
3. Уточняющий вопрос → «Нужно уточнение». ✅
4. Внутренняя заметка — заявителю не видна (отдельный список notes). ✅
5. Соисполнитель / запрос передачи → оператор(админ) подтверждает. ✅
6. Рекомендации → «Ответ готов». ✅

## С5 Возврат и ветка «не помогло» (мобильное)
1. Ввод трек-номера, ответы эксперта видны в чате. ✅
2. «Это не помогло» + причина → «Возвращено» (`/appeals/{track}/return`). ✅
3. Возврат идёт оператору, не сразу эксперту (очередь оператора со статусом returned). ✅
4. Оператор переназначает → заявитель подтверждает → оценка. ✅
5. Неверный трек-номер → 404; rate-limit 5/мин. ✅

## С6 Кризисное обращение (мобильное)
1. Текст с кризисным маркером (словарь `crisis.py`). ✅
2. Заявителю сразу показываются контакты помощи (блок в Submit). ✅
3. Предложен способ связи — можно отказаться. ⚠️ (UI-заглушка, contact сохраняется)
4. В очереди оператора — отмечено и сверху (`is_crisis DESC`). ✅
5. Оператор ставит «Срочно» и назначает специалиста. ✅

## С7 Администрирование (веб)
1. Добавить категорию. ✅
2. Правило маршрутизации (категория → группа + лимит). ✅ (лимит `max_active_appeals`)
3. Завести оператора/эксперта. ✅
4. Тестовое обращение → подсказка соответствует правилу. ✅
5. Изменить статус зависшего + запись в журнале (AdminLog + reason). ✅

## С8 Аналитика (веб)
1. Дашборд: метрики за период, нагрузка, доля возвратов. ✅
2. Выгрузка CSV без текстов обращений. ✅
